# x-scout-feed

Public excerpts of X (Twitter) posts collected via X search, about non-technical people building with AI and
lessons from building AI agents / vibe coding / automation.

- Each item links to the original post on x.com; excerpts may be truncated.
- Author claims are self-reported and **unverified**.
- Fixed URLs (branch `main`):
  - RSS: https://raw.githubusercontent.com/ncihxaonn/x-scout-feed/main/feed.xml
  - JSON: https://raw.githubusercontent.com/ncihxaonn/x-scout-feed/main/items.json
  - Status: https://raw.githubusercontent.com/ncihxaonn/x-scout-feed/main/status.json
